# 🏔️ Горнолыжная школа «Экстрим-Высота»

Адаптивный одностраничный лендинг (Landing Page) для горнолыжной школы и клуба. 
Проект разработан в рамках выполнения лабораторных работ по дисциплине «Информатика».

## 🎯 О проекте
Сайт представляет собой визитную карточку школы, демонстрирует услуги, цены и отзывы учеников. Главная цель — привлечение клиентов и сбор заявок на пробные уроки через форму обратной связи.

## ✨ Основные возможности
- **Адаптивность:** корректное отображение на компьютерах, планшетах и смартфонах (Flexbox, CSS Grid, Media Queries).
- **Sticky-навигация:** меню фиксируется в верхней части экрана при прокрутке.
- **Плавная прокрутка:** перемещение между разделами происходит плавно (`scroll-behavior: smooth`).
- **Интерактивность:** наличие hover-эффектов (увеличение кнопок, изменение цвета карточек), мобильное меню-гамбургер.
- **Семантическая разметка:** использование тегов HTML5 (`header`, `section`, `footer`, `nav`).

## 🛠 Стек технологий
- **HTML5** (структура)
- **CSS3** (оформление, анимации)
- **JavaScript** (интерактивность, работа меню и формы)
